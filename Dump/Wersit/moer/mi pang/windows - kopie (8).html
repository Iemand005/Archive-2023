Windows

Windows Verkenner

Verkenner is een zeer belangrijk onderdeel. Op Windows dient de verkenner voor de volgende onderdelen:

  • Bureaublad
  • Taakbalk
  • Bestand beheer

Zonder Verkenner kan je niet veel doen op Windows, je hebt de taakbalk nodig om makkelijk van programma te wisselen. Bestand beheer is een van de meest simpele dingen die je moet doen op elke computer. Het bureaublad is niet noodzakelijk maar wel iets wat iedereen verwacht dat werkt. Op Mac OS werkt het ongeveer hetzelfde, maar de taakbalk en achtergrond worden getekend door een apart programma.

Geschiedenis in grote lijnen

  • Windows 1 tot 3.1

    Het doel van Windows was om een gebruiksvriendelijke manier te hebben om met computers te werken. Windows was uitgebracht nadat Apple met de Apple Lisa hun eerste grafische interface ontworpen hadden. Microsoft moest dus snel hun eigen systeem maken dat boven op MS-DOS werkte. Apple was natuurlijk boos dat Microsoft hun concept van grafische interface met icoontjes, vensters en een computer muis gekopieerd had, maar ze konden het niet meer tegen houden.
