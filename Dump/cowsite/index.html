Ik en HTML

Ik heb vaak naar HTML gekeken bij inspecteer element in de browser, maar begreep er eerst niets van. Pas rond het tweede middelbaar begon ik te snappen wat het allemaal betekende. Ik had een kloon van Smartschool gemaakt, genaamd Dumbschool. Ik vind de bestanden hiervan niet meer, het zou kunnen dat ik het per ongeluk heb verwijderd.

Wat ik wel gevonden heb is een kleine demo van 3 jaar geleden. (Hoort niet bij de opdracht want dit gebruikt css en zo.) Dit was gewoon om de Chrome kleuren op Android te testen, maar is leuk als basis voor een site met tabbladen.

Ik heb al echte websites gemaakt, maar ik gebruik normaal javascript en css om het wat op te vrolijken. Puur HTML zorgt voor websites die er uit zien alsof ze voor monochrome Macintosh computers of een Nokia 3410 gemaakt zijn.

Een iets bekendere website van mij was MPTool. Dit is een oudere versie, ik ga de nieuwere niet meer delen aangezien mensen de functies er in misbruikt hebben. Het was bedoeld as front-end voor de Microsoft PlayFab api, maar je kon nog veel meer door een gebrek aan beveiliging op hun einde.
